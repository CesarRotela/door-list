# Door List

Door List is a single-event landing page built with Next.js, React, TypeScript, and Tailwind CSS.

## Run locally

Install Node.js and npm, then run:

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current scope

The event title, date, and venue are hardcoded in `app/page.tsx`. The registration button is a visual placeholder: it does not submit data or register attendees. There is no database or authentication.

## Production build

```bash
npm run build
npm run start
```

The project currently has no test or lint scripts.
